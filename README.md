# 项目目标

构建一个具备多级记忆与知识库管理能力的轻量级智能对话系统，支持用户上传文档（如 TXT、PDF），自动将其转化为可检索的知识库，并在对话中实现上下文连贯的 RAG（检索增强生成）问答体验。

核心特性：

- **多级记忆**：会话级、项目级、全局记忆（MVP 阶段仅实现会话与项目记忆，且不持久化）
- **知识库管理**：支持文档上传 → 文本提取 → 向量化 → 存入向量库
- **RAG 能力**：基于用户提问，自动检索相关知识片段并注入 LLM 提示
- **本地优先**：嵌入模型与向量库均支持本地运行，无需依赖外部 API（除 LLM 外）



# 技术选型

| **模块** | **技术栈**                                                   |
| :------: | ------------------------------------------------------------ |
|  主框架  | Spring Boot 3.5.6 + Java 21                                  |
| 文档解析 | Apache Tika 3.2.3                                            |
|  向量库  | Chroma（Docker 容器部署，端口映射`18005:8000`），文档访问地址为：http://127.0.0.1:18005/docs/#/ |
| 嵌入模型 | `AllMiniLmL6V2QuantizedEmbeddingModel`（LangChain4j 内置，ONNX，CPU 可运行） |
| RAG 框架 | LangChain4j 1.5.0（含`langchain4j-easy-rag`、`langchain4j-chroma`、`langchain4j-embeddings`） |
|   缓存   | 前期使用内存`ConcurrentHashMap`，后期引入 Redis              |
| LLM 集成 | 后期可选 OpenAI / Ollama / 阿里百炼                          |



# 开发规划

## 阶段一：基础框架搭建 + 知识库索引能力建设

**目标**：实现“上传文档 → 自动转为知识库”全流程
**当前状态**：已完成

**完成内容**：

- 项目基础环境搭建完成（Spring Boot + LangChain4j + Chroma）
- 支持用户上传文档并自动解析为可检索的知识库
- 提供知识库检索接口，验证 RAG 索引流程可用



## 阶段二：记忆系统 + RAG 检索集成

**目标**：实现会话/项目记忆 + RAG 增强提示
**当前状态**：进行中

**计划内容**：

- 实现内存级多级记忆：
  - 会话记忆：按 `sessionId` 存储对话历史
  - 项目记忆：按 `projectId` 隔离知识库（通过 Chroma collection 或元数据）
- 构建 `ContentRetriever`，支持基于用户提问的语义检索
- 实现 RAG 检索逻辑：提问 → 检索 Top-K 知识片段 → 拼接至提示词
- 提供 `/chat` 接口雏形，返回检索结果与上下文（暂不调用 LLM）

**关键取舍**：

- 记忆不持久化（重启丢失），聚焦流程验证
- 项目隔离通过 Chroma collection 命名实现（如 `kb_project_{id}`）
- 检索结果按余弦相似度排序，设置合理阈值避免噪声

## 阶段三：LLM 集成 + 基础前端

**目标**：端到端问答闭环 + 简易交互界面
**当前状态**：待开发

**计划内容**：

- 集成 LLM：
  - **方案 A（联网）**：OpenAI / 阿里百炼（需配置 API Key）
  - **方案 B（本地）**：Ollama（如 `qwen:7b`、`llama3`）
- 实现完整 RAG 流程：
  - 接收用户消息 → 获取会话历史 → 检索知识库 → 构建提示 → 调用 LLM → 返回答案
- 提供简易前端
