## 通用字段

- id：主键，唯一标识
- create_time：数据创建时间
- create_by：数据创建人
- update_time：数据更新时间
- update_by：数据更新人
- status：数据状态
- del_flag：逻辑删除状态

## 角色表 - role

- 存储自定义角色性格特征

- role_name：角色名称
- description：角色描述，用于详细说明该角色的性格特征
- default_flag：是否全局默认角色

## 项目表 - project

- 存储项目信息，便于进行分组、分类管理

- project_name：项目名称
- role_id：关联的角色，项目的默认角色

## 会话表 - session

- 存储会话信息

- project_id：项目id，用于关联项目（项目会话），可为空（全局会话）
- role_id：关联的角色，会话使用的角色
- session_title：会话标题

## 消息历史表 - message

 - session_id：关联 session 表中的会话 ID
 - role：消息发送者角色（例如：user、assistant）
 - content：消息内容
